# Colors

The color system has **two layers**:

1. **Primitives** — raw color ramps (`--color-{family}-{stop}`). Mirror Figma `color/{family}/{stop}` 1:1. Don't consume these directly in components.
2. **Semantic tokens** — role tokens (`--surface-*`, `--text-*`, `--border-*`, `--action-*`, `--status-*`) that bind to primitives. **Components consume these.** Light mode is the default; dark mode is the same token names remapped under `[data-theme="dark"]`, so component CSS never changes between themes.

Source of truth: `src/tokens/color.css`. The hexes below are the resolved values.
